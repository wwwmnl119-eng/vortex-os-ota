# Vortex OS — обновления

Отсюда приложение «Обновления» в Vortex OS узнаёт о новых версиях.

- `a20.json` — последняя сборка для Samsung Galaxy A20 (SM-A205F).
- Сами прошивки лежат в [Releases](https://github.com/wwwmnl119-eng/vortex-os-ota/releases).

Ставить вручную: TWRP → Install → zip. При переходе с другой прошивки нужен Format Data.
